## Package Management with APT

Ubuntu uses the Advanced Package Tool, or APT, to manage software packages.

Packages are normally retrieved from configured software repositories rather than downloaded and installed manually.

### Search for a Package

```bash
apt search "package name"
```

For example:

```bash
apt search "midnight commander"
```

This searches the configured repositories for packages matching the supplied term.

---

### Install a Package

```bash
sudo apt install package-name
```

For example:

```bash
sudo apt install mc
```

Because installing software affects the entire system, elevated privileges are normally required.

---

## Software Repositories

Linux distributions typically maintain repositories containing software packages that have been prepared for that distribution.

APT retrieves information about these packages and their dependencies from the repositories configured on the system.

Repository configuration on modern Ubuntu systems can be found under:

```text
/etc/apt/sources.list.d/
```

For example:

```text
/etc/apt/sources.list.d/ubuntu.sources
```

These files define where APT retrieves software and package information.

## Midnight Commander

Midnight Commander can be launched with:

```bash
mc
```

Midnight Commander, commonly abbreviated as `mc`, is a text-based file manager that runs directly inside the terminal.

Its dual-pane interface allows files and directories to be browsed and manipulated without relying entirely on individual shell commands.

Some useful functions include:

- Navigating directories
- Viewing files
- Copying files
- Moving files
- Renaming files
- Deleting files
- Searching through the filesystem

### Useful Keys

View the currently selected file:

```text
F3
```

Exit Midnight Commander:

```text
F10
```

The interface provides shortcuts for many common filesystem operations while still operating completely within a terminal session.

## Linux Filesystem Hierarchy

Linux uses a standardized directory structure where directories generally serve specific purposes.

The hierarchy can be reviewed directly from the manual:

```bash
man hier
```

Several important directories explored during this lesson included:

### `/root`

```text
/root
```

The home directory for the `root` user.

Unlike normal users, whose home directories normally exist under `/home`, the root user's home directory exists directly beneath `/`.

---

### `/home`

```text
/home
```

Contains home directories for normal users.

For example:

```text
/home/tankouban
```

User-specific files, configuration files, documents, and other personal data are generally stored within the user's home directory.

---

### `/etc`

```text
/etc
```

Contains system-wide configuration files.

Many important Linux services store their configuration under `/etc` or one of its subdirectories.

Examples include:

```text
/etc/passwd
/etc/ssh/sshd_config
```

---

### `/var`

```text
/var
```

Contains data that is expected to change while the system is operating.

This includes data such as:

- Logs
- Caches
- Spool files
- Application state

---

### `/var/log`

```text
/var/log
```

Contains logs generated by the operating system and installed services.

Logs are extremely useful for:

- Troubleshooting
- Security investigations
- Service monitoring
- Auditing system activity

---

### `/sbin`

```text
/sbin
```

Traditionally contains binaries primarily intended for system administration.

Modern Linux distributions may organize or link some of these directories differently, but understanding the traditional filesystem hierarchy remains useful when working across Linux environments.

---

## Configuration Files

Linux configuration is heavily based on text files.

Many system-wide configuration files are stored beneath:

```text
/etc
```

Because these files are plain text, they can be viewed and modified using standard command-line tools and text editors.

Two files reviewed during this lesson were:

```text
/etc/passwd
/etc/ssh/sshd_config
```

---

## `/etc/passwd`

```bash
cat /etc/passwd
```

The `/etc/passwd` file contains account information for users and system accounts.

Each line represents an account and contains several colon-separated fields.

Typical information includes:

- Username
- User ID
- Group ID
- User information
- Home directory
- Login shell

Despite the filename, modern Linux systems do not normally store password hashes directly inside `/etc/passwd`.

Password hashes are typically stored in the more restricted:

```text
/etc/shadow
```

---

## SSH Server Configuration

The OpenSSH server configuration can normally be found at:

```text
/etc/ssh/sshd_config
```

This file controls server-side SSH behavior.

Configuration options can affect things such as:

- Authentication
- Login permissions
- Port configuration
- Root login
- Public-key authentication

Changes to SSH configuration should be made carefully because an incorrect configuration can potentially prevent remote access to the server.

---

## System Logs

On Ubuntu systems, authentication-related events may be recorded in:

```text
/var/log/auth.log
```

This can contain information related to:

- SSH logins
- Failed authentication attempts
- `sudo` activity
- User authentication

System logs are among the first places to investigate when troubleshooting services or reviewing suspicious activity.
